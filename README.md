# easy-a2t

easy-a2t は、ブラウザからアップロードした音声ファイルを`faster-whisper`で文字起こしするだけのプログラムです。

文字起こし結果は、サーバーを起動したディレクトリに `アップロードしたファイル名.txt` として保存されます。各行には開始時刻、終了時刻、認識テキストが出力されます。

```text
[0.00 -> 3.42] こんにちは、これはテストです。
```

ただの`faster-whisper`なのでベンチマークはいらない気がしますが一応。

| 音声ファイルの長さ | CPU(Ryzen 9 9950X)での文字起こし時間 | GPU(RTX 3090)での文字起こし時間 |
| ---- | ---- | ---- |
| 2,084 sec | 360 sec | 57 sec |

6分

## 必要なもの

- Python 3.11 以上
- `uv` 推奨
- 初回実行時に Whisper モデルを取得できるネットワーク環境

**GPUを使う場合**

`faster-whisper`の実行環境が必要です。~~ただのラッパーなので~~
- cuBLAS for CUDA 12
- cuDNN 9 for CUDA 12

また、`main.py`にて
```python
use_gpu = True
```
としてください。

**CPUを使う場合**

CPUでの実行はおすすめしません。
そのうえでCPUで動かしたいなら、`main.py`にて
```python
use_gpu = False
```
としてください。

## セットアップ

`uv` を使う場合:

```powershell
uv sync
```

`uv` を使わない場合:

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -e .
```

## 起動方法

ローカル PC だけで使う場合:

```powershell
uv run fastapi dev main.py
```

同じ LAN 内のスマートフォンや別 PC からアクセスしたい場合:

```powershell
uv run fastapi dev main.py --host 0.0.0.0
```

起動後、ブラウザで以下を開きます。

```text
http://localhost:8000
```

## 使い方

1. トップページを開きます。
2. 音声ファイルを選択します。
3. 送信ボタンを押します。
4. サーバー側でバックグラウンド処理が開始されます。
5. 処理が終わると、起動ディレクトリに `ファイル名.txt` が作成されます。

## 注意点

- 認証やアクセス制限はありません。インターネットへ公開する用途には向きません。
- 出力ファイルは起動ディレクトリに直接保存されます。同名ファイルがある場合は上書きされます。
- 送信後の画面には、文字起こしの進行状況や完了通知は表示されません。出力ファイルの作成状況を確認してください。
- 文字起こしの言語は固定です。別の言語を文字起こししたい場合は`main.py` の `language="ja"` を変更してください。
- QR コードはサーバー起動時の IP アドレスをもとに生成されます。
